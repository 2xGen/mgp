# **App Name**: GoProfile Manager

## Core Features:

- GBP Connection: Allow users to securely connect their Google Business Profile.
- Stats Overview: Display key stats from the connected GBP (e.g., views, clicks, calls).
- Review Analysis: Analyze customer reviews to identify common themes (using sentiment analysis tool).
- Review Display: Display the recent customer reviews with options to sort by date and rating.
- Q&A Management: Allow users to view and respond to customer questions.
- Reporting Dashboard: A summary page combining the stats, recent reviews and the Q&A

## Style Guidelines:

- Primary color: HSL 210, 70%, 50% - RGB Hex #3399FF (a vibrant blue, suggesting trust and technology).
- Background color: HSL 210, 20%, 95% - RGB Hex #F0F5FA (a very light tint of blue, nearly white, to ensure content is readable and avoid eye strain).
- Accent color: HSL 180, 60%, 40% - RGB Hex #33CCCC (a contrasting, desaturated cyan that draws attention without overpowering the design).
- Body text: 'PT Sans', a friendly and modern sans-serif, suitable for readability.
- Headline text: 'Space Grotesk', to pair with PT Sans, since the app includes data visualization; it creates a scientific feel. 
- Use simple, line-based icons for a clean and professional look.
- Use a card-based layout to organize information effectively.
- Use subtle transitions and animations to improve user experience (e.g., when loading data).
